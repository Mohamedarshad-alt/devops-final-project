# End-to-End DevOps Automation on AWS

## Project objective

Build and operate a Node.js REST API using automated infrastructure
provisioning, server configuration, containerization, CI/CD, security
scanning, HTTPS, monitoring, logging, backup, rollback, and recovery.

## Technology stack

- Node.js and Express
- PostgreSQL
- Terraform
- Ansible
- Docker and Docker Compose
- GitHub Actions
- GitHub Container Registry
- Nginx and HTTPS
- Prometheus and Grafana

## Project status

Phase 1: Project planning and repository setup.

## Planned API endpoints

- GET /health
- GET /api/v1/items

## Planned deliverables

- Application source and automated tests
- Terraform and Ansible configurations
- Docker and Nginx configurations
- CI/CD and security workflows
- Monitoring dashboards and alert rules
- Architecture diagram
- Test and security evidence
- Deployment and operations runbooks
- Backup, restoration, rollback, and recovery evidence

## Security rules

Never commit passwords, tokens, private keys, production environment
files, or unredacted sensitive screenshots.
